# CalculatorGrupp8

Andrea, Sintia och Eric

Testning av en enkel miniräknare med addition, subtraktion, multiplikation, division och roten ur.
Html, CSS, Javascript

## Installation

- Installera beroenden:
  npm install

## Starta applikationen

- Tryck på "go live server" längst ner till höger.

## Testkommandon

- Kör tester i watch-läge: npm test
- Kör tester en gång: npm run test:run
- Kör eslint: npx eslint

## Testresultat

- 8/8 tester godkända (tests/calculator.test.js)

- testa addition med positiva tal
- testa subtraktion med positiva tal
- testa subtraktion med negativa tal
- testa division med positiva tal
- testa division med noll
- testa squareRooten av ett positivt tal
- testa squareRooten av ett negativt tal

## Dokumentation

- Manuella testfall fins i mappen `Dokumentation`.
- Rapport finns i mappen `Dokumentation`.
